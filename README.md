# MotorFisicas3D

Aplicación de escritorio desarrollada en **Visual Basic .NET** que permite visualizar y ejecutar diversas pruebas de simulación de físicas en un entorno 3D.

---

## 📋 Descripción

MotorFisicas3D es un motor de físicas tridimensional orientado a la demostración y el aprendizaje. Permite ejecutar múltiples pruebas de simulación física en 3D, incluyendo colisiones, gravedad, cuerpos rígidos y más, todo ello dentro del entorno de desarrollo .NET y usando Visual Basic como lenguaje principal.

---

## ✨ Características

- Simulación de físicas 3D en tiempo real
- Múltiples escenas de prueba precargadas
- Visualización interactiva de los resultados
- Implementado en Visual Basic .NET
- Entorno de desarrollo con .NET Framework

## ⚙️ Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- [Visual Studio](https://visualstudio.microsoft.com/) (recomendado 2019 o superior)
- .NET Framework (versión compatible con el proyecto)

---

## 🚀 Instalación y ejecución

1. **Clona el repositorio:**

   ```bash
   git clone https://github.com/Abel-RV/MotorFisicas3D.git
   ```

2. **Abre la solución:**

   Abre el archivo de solución (`.sln`) con Visual Studio.

3. **Compila el proyecto:**

   En Visual Studio, selecciona `Compilar > Compilar solución` o pulsa `Ctrl+Shift+B`.

4. **Ejecuta la aplicación:**

   Pulsa `F5` o haz clic en el botón **Iniciar** para arrancar la aplicación.

---

## 🎮 Uso

Al iniciar la aplicación, podrás seleccionar entre las distintas pruebas de físicas 3D disponibles. Cada prueba demuestra un aspecto diferente del motor de físicas:

- **Gravedad y caída libre**: Observa cómo los objetos caen bajo la influencia de la gravedad.
- **Colisiones**: Prueba el comportamiento de los cuerpos al colisionar entre sí.
- **Cuerpos rígidos**: Simulación de objetos sólidos con propiedades físicas reales.
- **Otras pruebas**: Diversas simulaciones adicionales incluidas en el proyecto.
